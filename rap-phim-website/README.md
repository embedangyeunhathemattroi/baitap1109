# CineBox – Đặt vé xem phim mini

Website **đặt vé** *xem phim mini*.

| Thư mục | Nội dung | Chú Thích |
|---|---|---|
| `docs` | Biên bản bàn giao và ảnh môn học | Tài liệu dự án |
| `data` | File Excel bán vé | Dữ liệu đặt vé |
| `logs` | Nhật ký và báo cáo tổng hợp | Theo dõi sự cố |

```powershell
Get-ChildItem -Recurse -Force
```
